# Contexto del Proyecto: Portafolio Personal

## 🛠️ Stack Tecnológico
- **Framework/Bundler:** Vite + React (o el framework que estés usando).
- **Lenguaje:** TypeScript.
- **Estilos:** CSS/SCSS o Tailwind (ajusta esto según uses).
- **Entorno:** Node.js con pnpm.

## 🧠 Reglas de Comportamiento del Agente
1. **Código Limpio:** Mantén los componentes modulares y reutilizables. No generes código espagueti.
2. **TypeScript Estricto:** Asegúrate de tipar correctamente todas las props y estados.
3. **No rompas la estructura:** Respeta la arquitectura de carpetas existente (`src/`, `public/`, etc.).

## 🧰 Habilidades Globales (Skills)
Tienes acceso a habilidades instaladas globalmente en `~/.agents/skills/`. Úsalas proactivamente cuando la tarea lo requiera:
- Usa `design-taste-frontend` para asegurar un diseño premium, moderno y con alta varianza visual.
- Usa `awesome-design-md` para extraer paletas de colores y tipografías de sitios como Stripe o Linear.
- Usa `web-design-guidelines` para auditar la accesibilidad y UX del código final.
- Usa `playwright` para levantar el servidor local, tomar capturas y verificar que el diseño responsive no se rompa.
- Global Skills: También tienes acceso a las habilidades instaladas globalmente en `~/.agents/skills/` (en Windows: `C:\Users\REDECS2\.agents\skills\`). Úsalas si son relevantes para la tarea.
